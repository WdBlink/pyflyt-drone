# Privileged-to-Perceptual Fixed-Wing Guidance Paper

This directory is the repository-local paper workspace. Scientific intent and
claim gates are maintained in [`ctx/spec/02-privileged-perceptual-guidance.md`](../ctx/spec/02-privileged-perceptual-guidance.md), and the decision to pursue this
line is recorded in [`ctx/decisions/0002-privileged-perceptual-mainline.md`](../ctx/decisions/0002-privileged-perceptual-mainline.md).

No result, superiority, safety, deployment, or SOTA claim is admitted merely
because a manuscript file exists. Result sections are generated only after the
frozen evaluator and confirmatory evidence gate pass. Before that point this
directory may contain only source material, protocol files, templates, and
clearly labeled pilot outputs.

Generated checkpoints, raw rollouts, detector weights, logs, and render outputs
remain outside Git. Small manifests, aggregate tables, figure source data, and
provenance records may be committed when they contain no machine-specific paths.

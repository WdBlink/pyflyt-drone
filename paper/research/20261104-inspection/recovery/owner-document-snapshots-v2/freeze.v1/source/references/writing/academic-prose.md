# 论文表达：读者、论证与保真

本地写作补充，非 Deli 原文。用于论文起草、文风修订、摘要、图注和写作评审。按具体阅读障碍改写，不套禁词表，也不以 AI 检测器分数验收。

“AI 味”在这里指空泛、模板重复、论证跳跃、表达费解、无信息的反复保留或证据失真等可定位的问题，不据此判断作者身份。词频、局限性篇幅和文风偏好都不能单独作为判错依据。

完整起草或多段修订时，先浏览 [案例索引](academic-prose-examples.md#怎样使用)，按当前问题读取相应案例的前提、改法、反例与核对要求；局部修改和评审只读匹配案例。委派时一并提供相关案例路径或例号。案例用于选择操作，不是可直接填入论文的事实或固定句型。

## 关键写作约束

- **写研究关系，不写工作流水账。** 把编辑和运行顺序改写为研究对象、样本组成、实验条件与比较关系。与复现无关的路径、TODO 和运行输出留在工作记录；预先设计、标签访问、数据复用、评估器修复等影响证据解释的时序必须保留。
- **尽早交代真正的问题。** 引言避免长篇通用背景，摘要避免堆项目功能；说明具体缺口、已有观察和当前研究为何必要。可前移已有开发观察，但要保留其身份，不能编造反例或把开发发现写成独立验证。综述可从文献争议和证据缺口展开。
- **让评价落到可核对的内容。** 对 novel、robust、comprehensive、显著、赋能、具有重要意义等表达，检查它承担了什么主张：新在哪里、对什么扰动稳健、覆盖什么范围、相对谁改善。缺少支撑时删去评价或缩小范围，不能补造事实。统计语境中的 significant 必须有相应检验依据；实际重要性另用效应大小和应用条件说明。这些词本身不是禁词。
- **先解释选择，再介绍术语。** 方法先讲要估计什么、为何如此定义及必要假设，再给公式与模型命名。术语在需要时定义并保持一致；已充分定义的概念、必要记号表和期刊规定的顺序无需强行重排。
- **用具体发现代替图表导览。** 结果段落应回答一个问题，用明确的指标、比较对象、数值和图表支撑判断，并交代影响该判断的条件与不确定性；已说明且仍适用的条件不逐段重复。把 better/worse 写成具体指标方向。复杂图可以先解释读法，但不能让“Figure shows…”代替分析，也不能把混合结果硬写成全面胜出。
- **保留明确的研究动作。** 允许 We compare/test/design 等准确表达，不为正式感机械删除第一人称、堆叠抽象名词或使用被动句。必要术语可以重复，不强制同义替换；遵守期刊的明确文体要求。
- **让句子的信息顺序支持理解。** 读者难以跟随时，把已知话题放在句首、主要判断放在主句，让主语和核心动词靠近；把动作从名词堆中恢复为动词。按上下文话题选择主动或被动，修正 this/these/上述结果的模糊指代和悬垂修饰。长句、被动句及必要的术语重复可以保留，不设置字数、句长变化或词汇多样性的配额。
- **结论强度与证据一致。** 清楚陈述已支持的发现，同时区分观察、候选解释和外推。已观测的结果或已完成的证明不因机制或推广范围尚不确定而一并弱化；条件与保留措辞只修饰受影响的主张。保留影响解释的失败、探索性身份和反证，不能把候选解释升级为机制证明，也不能把证据明确的结论降成猜测。
- **引用贴近其支持的主张。** 避免在多个不同主张后统一挂引用；区分背景相关性、具体方法归属和本研究选择。拆句或移动引用后重新核对支持范围，不能仅查 citation key；某篇文献不支持一个模型，不等于该模型首次提出。
- **保真要核对关系，不只核对字符。** 对照改写前后的对象、指标、数据集、基线、分母、单位、区间、实验身份与结论强度。数字集合不变、引用数量不变、编译成功或关键词零命中，都不能代替语义核对。

## 局限与保留措辞的分量

- **先判断影响，再决定是否写。** 每条局限应指出影响哪项主张，以及如何改变其可信度、解释或适用范围。区分会动摇当前结论的缺陷、限制外推的研究范围、可选的后续扩展；未覆盖所有场景不自动否定范围内的发现。若当前结论依赖未验证条件，则必须缩小或撤回相应主张，不能仅将问题改名为“范围”或补一句免责声明。
- **按阅读需要安排位置。** 缺少某条件会让当前主张产生误读时，就近说明；共同的方法条件集中交代，讨论部分展开关键影响。摘要和结论保留理解核心发现所必需的边界，图注保留独立阅读所需的条件。重复只在这些阅读功能需要时保留，不设每段局限配额，也不设全文只能提一次的硬规则；期刊明确要求的局限章节仍须满足。
- **把不确定性落到具体层次。** 直接报告样本内观察，同时保留相关的区间、变异或检验结果；观察到的差异不自动证明总体优势或因果机制。避免“可能在一定程度上提示潜在……”等重复弱化。已有明确对象、范围和证据的陈述，不再无条件叠加 may、perhaps、初步、一定程度等词。
- **压缩无新增信息的保留。** 合并重复局限，删去不能说明具体影响的“结果仍需谨慎解释”“仍需进一步研究”等尾句。确需后续研究时，说清要解决的未知及所需证据；不为每个发现补研究计划，不编造缺陷来显得客观，也不把已知重大缺陷因措辞重复而删掉。
- **让发现和贡献得到完整表达。** 结尾收束已经回答的问题及其意义，按必要程度说明边界或下一步，不固定采用“肯定一句—转折否定一句”的节奏。若核心问题仍未解决，明确实际得到的结果与未解决项，不强行写成成功，也不把其他已支持的结果全部降格。

具体对照见 [E06：局限去重及必须保留的反例](academic-prose-examples.md#e06)、[E07：均值、区间和样本对应](academic-prose-examples.md#e07) 与 [E09：无需弱化的结论](academic-prose-examples.md#e09)。

## 定位问题的四个读法

按当前稿件的问题选用，不要求每段逐项打卡。

1. **反向提纲。** 抽取各段的核心主张或作用，连起来读，检查问题、选择、证据、解释之间是否缺前提或重复。不要假定首句一定是主题句。若只能读出“介绍背景—介绍模型—介绍图表”，补足已有材料支持的研究关系；逻辑缺口不能靠 moreover、therefore 或“综上”掩盖。
2. **可替换性与删除检查。** 把领域或模型名遮住后，句子若适用于几乎任何论文，再检查删除它是否损失必要定义、背景、论证或过渡。无损才删除；需要具体信息时从原始材料补齐，材料没有就记录缺口。反复出现的三点贡献、排比或段末总结，只有造成重复或错误分类时才重组；不能为结构整齐硬凑贡献，也不能一律删去路标。
3. **选择与代价检查。** 方法和讨论应让读者理解关键设计依据，以及影响判断的替代方案、代价、例外和不利结果；不用穷举所有未做的工作。只使用有记录或可论证的理由；不得事后编造研究动机，把探索写成预先计划，或为“作者声音”虚构经历与判断。
4. **主张范围检查。** 双向核对：既检查单个数据集是否被扩成普遍结论、相关性是否被写成因果、平均改善是否被写成所有样本改善，也检查已支持的发现是否被弱化成猜测、未评估是否被写成无效。核对否定、量词、条件与不确定性；英语时态改变可能改变主张范围，应结合上下文判断，不能把时态本身当作错误。

## 写作与评审怎样接入

1. **明确段落任务。** 读取目标章节及上下文，确定读者此处要解决的问题、已有证据和必要边界。修订已有稿件时保留基准版本，不为“像人写”增加口语、错别字或随机句式。
2. **先理顺论证，再清理措辞。** 用上面的读法定位问题，先处理证据失真和逻辑缺口，再处理句子负担。Claim–Evidence–Implication 等是可选逻辑工具，不逐段复制同一模板。每次修改应能说清具体障碍；对已经准确清楚的段落保留原文，避免反复全文“人类化”改写及漂移。
3. **保真检查（Gate 3）。** 对实质改写或搬移的段落，逐项核对方法事实、公式、数值对应关系、引用支持范围和影响解释的条件。检查主张被夸大或无据弱化两个方向；合并局限后核对其必要信息仍可获得，不要求原措辞和重复次数不变。在现有修订记录中简记“位置 → 改法 → 理由 → 核对结果”，不新建重复账本。
4. **读者检查（Gate 5）。** R3/R5 先仅凭成稿复述研究问题、关键选择、主要发现及适用范围，再与证据和作者意图对照；检查重复保留是否遮住发现，不能依靠修订说明补全正文缺失的逻辑。新增局限的评审意见须说明受影响主张、依据与具体后果，不能只说“应更谨慎”或“AI 味重”。涉及科学判断时交回相应专业角色。低风险措辞修改无需另起完整多 Agent 流程。
5. **检查成稿。** 修改 LaTeX 后运行适用的项目构建，检查引用及重排影响的 PDF 页面；交付源码包时复用既有干净解包构建检查。缺少编译条件时明确未验证部分，不把源码通读当成 PDF 检查。

正文与图注共同遵守这些规则；数值、统计和图表口径同时遵守 [实验图表补充](experimental-figures.md)。纯措辞偏好作为建议，主张与证据关系失真必须修正，不能用流畅度或模拟评分补偿。仅维护本技能时不启动论文流程。

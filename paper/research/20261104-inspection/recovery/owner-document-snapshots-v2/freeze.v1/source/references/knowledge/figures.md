# Figures：从原始结果到图注与主张

Use registered `export_image` actions and `pdf-inspect` from [production.md](../production.md), with the current venue policy. Pixel dimensions, DPI and color mode are parameters; no font is inferred from raster pixels. The default statistics caption describes cases and sample SD without implying independent repetitions or an unused failure penalty.

采用用户 Deli 本地 `experimental-figures`、venue 校准和 PaperFlow 的 evidence-bound asset 方法。该文件为综合改写，图表领域判断由宿主实际执行，控制器负责证据版本和数值检查；没有运行过的视觉审阅不得写成通过。

## 先定义问题

读取当前冻结图表计划、原始实验记录、纳入排除/统计方案、venue 版式与模板。每张图表明确 question、支持的 claim、比较对象、指标/单位/方向、真实独立单位/n、失败与缺失分母。动机、方法和实验结果承担不同论证；装饰性流程图不能替代证据。

形态按问题选择：总体差异用点与适用区间，个体一致性用真实配对差值，尾部/失败用逐样本分布，有序真实测量才画曲线，真实网格才画热力图，可比成本才画质量成本权衡。只有汇总值时不能反推 ECDF 或发明逐 query 数据；只有重复 slots 时不能冒称独立样本或因果实验。

## 可复算的数值与资产链

保留 `原始结果 → 纳入集合/变换 → 绘图数值 → 图注 → 正文claim`。每个中间输入/sidecar 带路径及 hash、样本 ID、公式、筛选/聚合、区间计算单位和版本。资产依赖原始结果改变后必须失效重做；不能只更新 SVG/TeX 而沿用旧审阅。

- 区分 SD 的离散与 SE/CI 的估计不确定性，标区间类型/水平。小独立样本展示原始点并限制外推，不能用误差条制造总体可靠性。
- 真正配对须按样本/地点/主体 ID 对齐并保留聚类；同 seed 名称不足。对失败/超时说明分母，成功样本分布标为条件分布。
- 写出差值方向；比率须有有意义的零点和正基线。“聚合后比值”不等于“逐样本比值均值”。负 NLL 等不自动报告百分比。
- 可比方法/面板用相同单位与清楚轴域，不裁退化点、区间端点或离群值以强化结论。柱长比较通常从零起；局部放大须可见。
- 精确值留表，模式与异质性用图，正文解释结果与限制。未舍入值决定最优；显示精度并列时不能独占粗体。目标型指标按离目标的距离评估，不能一律最大为好。
- 定性案例按预先说明的 ID、分位或失败类型选择，保留普通及不利案例；各方法同底图、尺度和裁剪，不能各自缩放夸大差异。

## 图注与 PDF 验收

图注须让读者独立理解比较对象、点线区间、单位、n/统计单位、基线/分母、失败处理及被支持的结论。全文保持方法颜色/符号语义，并用形状/线型提供冗余；实际单/双栏尺寸下检查字、线、图例和灰度可辨识性。

用另一条最小计算路径核对关键数值，不能只调用同一个绘图函数自证。实际编译并读取所在 PDF 页面，检查截断、重叠、字号、图注/引用和分页；单图清楚或编译成功不等于成稿可读。源包还需在干净解包目录构建。缺原数据、成稿审阅或能力不支持某图型时说明缺口，不能补造测量。

输出图/表本体、绘图 sidecar、数值检查、图注和正文位置。每项绑定到 requirement ID；同一无关资产不能填多个承诺。交给 write/review 的包括全部负面与未实现项，而不是只有好看的导出图。

## 风格、图型与交付的适用范围

比较矩阵、benchmark/ablation 表、taxonomy 和跨论文综合各有不同数据合同；必要时分组、差值和精确绝对值共同呈现。图表计划从论证选择形态，不能按历史长综述的固定图表数量反推实验。三线表/无竖线、矢量统计图、足够分辨率照片和语义配色是常用选择，以目标模板和最终阅读尺寸检验，不机械统一十点字号、固定颜色或所有数据 mean±std。

当前数值 renderer 的可执行能力按实际 packet 和脚本限定；阶段知识中的 ECDF、Pareto、定性格或校准图是选型方法，不代表该 renderer 已支持全部图型。所需形态不支持时保留图表 brief 和能力缺口，使用已授权项目工具或明确扩展后再验证，不能自动降成错误统计或捏造逐样本数据。
